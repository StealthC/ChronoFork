# Phase 8.1 Design — Cartridge, region, TMSS and boot

**Date:** 2026-11-17
**Phase:** `8.1`
**Surface:** `Backend`
**Stage:** phase (one phase, implementation-ready)
**Status:** approved 2026-11-17

## Goal

Turn the immutable ROM blob into a modelled cartridge: parse and validate the header,
support images above 4 MiB through the Sega mapper, expose battery SRAM, derive the video
standard from the declared region, model TMSS VDP lockout, and let a synthetic cartridge boot
deterministically to a marker loop with all of that exercised.

## Approach

**Cartridge owns the cartridge.** A new `cartridge.rs` module holds the ROM image, the parsed
header, the Sega mapper register file, the SRAM array and the TMSS latch. `MegadriveBus`
delegates the ROM window (`0x000000–0x3FFFFF`), the mapper registers (`0x00A130F0`–
`0x00A130FF`), the SRAM window (`0x00200000–0x0020FFFF`) and the TMSS register
(`0x00A14000–0x00A14003`) to it, and keeps its existing typed bus errors. This keeps the
device model in one place instead of growing `MegadriveBus` with three more ad-hoc windows.
The alternative — fields directly on the bus — was rejected because mapper and SRAM state must
serialize and hash together, and a host-side-only loader cannot model bank switching.

**Header.** Parse the standard cartridge header: system string at `0x100` (`SEGA MEGA DRIVE`,
`SEGA GENESIS`, and the documented `SEGA 32X`/`SEGA PICO` strings are recognised only enough
to reject them as unsupported), copyright at `0x110`, domestic name at `0x120`, overseas name
at `0x150`, serial at `0x180`, checksum stored at `0x18E`, I/O support at `0x190`, ROM start
at `0x1A0`, ROM end at `0x1A4`, SRAM spec at `0x1B0`–`0x1BF`, region at `0x1F0`, computed
checksum over the whole image. Text fields are bounded ASCII (trimmed, lossy-decoded) so a
malformed image cannot allocate unbounded strings. `rom_end` must describe the image; a
mismatch is a typed `CartridgeError::HeaderMismatch` only when the image is shorter than the
declared end, because dumps are commonly padded to a power of two.

**Mapper.** The Sega/SSF2 mapper is always present and defaults to identity, so images up to
4 MiB behave exactly as today. Address space: `0x000000–0x07FFFF` is fixed to bank 0;
`0x080000 + i × 0x80000` for `i = 0..=6` is bank register `i` (registers `0xA130F3`,
`0xA130F5`, `0xA130F7`, `0xA130F9`, `0xA130FB`, `0xA130FD`, `0xA130FF`). Bank numbers are
9 bits, covering images up to 256 MiB of addressable page; a bank whose page lies beyond the
image is `CartridgeError::UnmappedRom`, which the bus reports as `UnmappedRead`. Byte writes
to the register window set the corresponding bank. `0xA130F1` bit 0 maps the 64 KiB SRAM at
`0x00200000–0x0020FFFF` over the ROM window, bit 1 write-protects it; all other registers are
stored but documented as having no modelled effect. `0xA130F0` and `0xA130F2` are ignored.
Identity banks for images at or below 4 MiB are established at construction, so a game that
never touches the mapper reads its image linearly.

**SRAM.** 64 KiB of battery SRAM is allocated at reset, zeroed, and is canonical machine
state: it is serialized in the snapshot, included in the state hash, and never in the
configuration hash. The header's SRAM spec is parsed and exposed for diagnostics but does not
restrict the hardware window. Writes while bit 1 of `0xA130F1` is set are rejected with the
existing write-protect error. Host save files are a separate policy layer: the CLI can import
and export raw 64 KiB SRAM images, and import replaces canonical state only at machine
construction (documented in the plan), never silently during a run.

**Region, video standard and TMSS.** Region is a bitfield parsed from `0x1F0`
(`J`, `U`, `E`; a missing byte is an error, unknown letters are rejected). The video standard
is PAL only when the header declares `E` and neither `U` nor `J`; otherwise NTSC. An explicit
configuration override exists for tests and for region-mismatched dumps. TMSS is a modelled
`TmssModel` (`Disabled` or `Enabled`) with **default `Disabled`** so the current baseline and
demos keep their bytes; phase 8.6 enables it for the commercial fixtures. The version register
at `0xA10001` reports `(export << 7) | (pal << 6) | 0x20 | (tmss_present as u8)`, matching the
documented layout (bit 7 export, bit 6 PAL, bit 5 no-disk, bits 0–3 hardware version) and the
Exodus reference implementation. With `Enabled`, a long write to `0xA14000` whose bit 9 is set
unlocks VDP writes; until then reads of `0xC00000–0xC0000F` return the unlocked value and
writes are acknowledged but discarded. The lockout is a canonical latch in the snapshot.

**State and configuration.** The payload magic becomes `CFMD68K3` with payload version 3; the
state hash magic becomes `CFMDSTATE3` and covers the CPU, tick, RAM, VDP, scheduler, mapper
registers, SRAM and TMSS latch. The configuration hash becomes `CFMDCONF3` and covers the ROM
SHA-256, derived video standard, TMSS model and mapper/SRAM capability flags. Payload versions
1 and 2 are rejected with the existing typed error, never interpreted.

**Boot evidence.** A new synthetic `cartridge_boot_rom()` writes the "SEGA" unlock, programs a
mapper bank, writes and reads back SRAM, and enters a marker self-loop. This is the boot proof
for the phase; the two commercial fixtures are parsed and their headers are hash-pinned, but
their main-loop boot remains phase 8.6 evidence because it needs the full CPU and VDP. The
capability report is unchanged (`rendering = false`, `audio = false`); no new capability is
claimed by parsing a header.

## Files / Modules Touched

- `crates/chronofork-megadrive/src/cartridge.rs` — new: header parse, mapper, SRAM, TMSS,
  snapshot.
- `crates/chronofork-megadrive/src/bus.rs` — delegate ROM/mapper/SRAM/TMSS windows; add
  `CartridgeError` mapping; keep existing typed errors.
- `crates/chronofork-megadrive/src/backend.rs` — construct from `Cartridge`, derive the video
  standard, payload v3, state/config hash v3, expose `cartridge()`/`tmss()`.
- `crates/chronofork-megadrive/src/interrupts.rs` — accept the derived `VideoStandard`.
- `crates/chronofork-megadrive/src/inspect.rs` — expose header/region/mapper/SRAM summary
  pseudo-registers (bounded).
- `crates/chronofork-megadrive/src/lib.rs` — exports.
- `crates/chronofork-megadrive/tests/cartridge.rs` — new integration tests.
- `crates/chronofork-cli/src/main.rs` — `--sram` import/export on the `megadrive` surface and
  `megadrive cartridge` inspection command.
- `docs/architecture/megadrive-slice.md`, `docs/requirements/functional.md` (FR-MD-011) —
  capability text only, after the phase closes.

## Tests

- Unit: header parsing from a synthetic header, region combinations, checksum match/mismatch,
  text-field bounds, SRAM spec parse, mapper identity and banked reads, bank beyond image,
  write-protect, TMSS lock/unlock, version register bits, snapshot round-trip and rejection of
  v1/v2 payloads.
- Integration: synthetic boot ROM reaches its marker with TMSS enabled; mapper switch changes
  the fetched instruction stream; SRAM survives snapshot/restore and fork; SRAM is absent from
  the configuration hash but present in the state hash; a fixture-dependent test parses
  Kid Chameleon and Chakan headers and pins system/region/serial/checksum (skips with an
  explicit reason when `.research/roms/` is absent).
- Regression: the existing test baseline passes; the synthetic `chronofork demo` stays
  byte-identical; `megadrive demo` stays deterministic across runs and is re-pinned only for
  the documented state-hash version bump, never loosened.

## Open Questions

None. The curated fixture list and TMSS default were decided with the owner on 2026-11-17.

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Header offsets are misread and a fixture is falsely rejected | Commercial evidence blocked | Pin offsets and both fixtures' facts in tests; keep unknown fields diagnostic |
| Mapper semantics differ from a particular game's expectations | 8.6 compatibility gap | Identity default for ≤4 MiB; bank test ROM; record the mapper variant in the capability page |
| TMSS default-on could break the existing baseline | Demo/test churn | Default `Disabled`; enable explicitly in 8.6 |
| SRAM in the state hash breaks older checkpoints | Session fixtures invalid | Version bump and reject-only policy, documented as a break |
