# Commercial Compatibility, Accuracy Evidence and Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the curated fixtures through boot, intro and TAS scenarios with deterministic evidence, record the honest compatibility matrix and H5 accuracy evidence, and reach measured interactive speed without changing behavior.

**Architecture:** A `chronofork-cli` compat runner drives the existing backend and writes deterministic JSON/Markdown reports; a bench command measures non-canonical throughput; the release profile gains LTO; optimizations are gated by the existing differential and determinism suites.

**Tech Stack:** Rust 2024, `chronofork-core`, `chronofork-backend-api`, `chronofork-sessions`, `chronofork-megadrive`, `chronofork-cli`, Python 3 (oracle harnesses).

**Spec:** `docs/superpowers/specs/2026-11-17-8.6-commercial-compatibility-design.md`

## Global Constraints

- Never commit a ROM, BIOS, firmware, game asset, frame, audio or save file. Evidence lives under
  ignored `.research/`; only hashes and verdicts are tracked.
- Fixture-absent runs skip with `fixture-absent` and never pass silently; CI never downloads a ROM.
- Bench numbers are host metrics and must never enter canonical state, state hashes or reports
  consumed by determinism tests.
- Any optimization lands only with the full differential/determinism suite green and before/after
  hashes unchanged.
- No "runs everything" claim; the matrix is per-title, per-scenario, evidence-linked.
- No payload/state change in this phase; state stays v7.

## Review Focus

- A run that hangs, faults or never reaches the probe must be reported as `failed` with the failing
  check, never as `booted`.
- Report output must contain no host path, token, wall-clock value or absolute ROM path.
- Two compat runs on the same machine must produce byte-identical JSON except for an explicitly
  non-canonical bench section (which the compat report must not contain at all).
- TAS verification must fail when the movie diverges; a missing movie is a skip, not a pass.
- An optimization that changes any frame/audio/state hash is a failure even if it is faster.
