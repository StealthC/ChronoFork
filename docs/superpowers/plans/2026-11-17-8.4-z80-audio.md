# Z80, Bus Arbitration and Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Z80 core, Z80 memory/bank map and 68000↔Z80 bus arbitration, the YM2612 six-channel FM and PSG, and a deterministic 48 kHz mixer/resampler exposed through the media seam.

**Architecture:** New `z80/` and `audio/{ym2612,psg,mixer,resample}.rs` modules; the Z80 steps in T-states (15 master cycles each) under a `Z80Bus` view of `MegadriveBus`. YM/PSG run at canonical rates, mix in integer arithmetic and resample to 48 kHz. Payload moves to `CFMD68K6` v6 and `Capabilities.audio` becomes true.

**Tech Stack:** Rust 2024, `chronofork-core`, `chronofork-backend-api`, `chronofork-megadrive`, `chronofork-cli`.

**Spec:** `docs/superpowers/specs/2026-11-17-8.4-z80-audio-design.md`

## Global Constraints

- No `unsafe`, no new third-party dependency, no `unwrap()` in production code; typed errors.
- Determinism: audio is a pure function of Z80 register writes and elapsed master cycles; no host
  clock, audio device or floating point in the mixing path.
- Exact internal PCM hashes across runs; cross-emulator audio evidence is device-state only.
- No BizHawk code or data. Exodus (MIT) translation is allowed only with provenance, notice/license
  updates and owner approval.
- State/format changes are reject-only and versioned (payload v6); older versions rejected.
- Every task ends with its own tests passing and a commit.

## Review Focus

- Z80 flags: `DAA`, `SCF/CCF`, block-op flags, half-carry and `PV` must match documented behaviour;
  `EI` must delay interrupt acceptance by one instruction.
- Z80 memory: `0x4000–0x7FFF` device windows must not alias the banked ROM; `0x8000–0xFFFF` must
  follow `0xA06000`.
- Arbitration: a 68000 access while the Z80 owns the bus must stall deterministically and never read
  torn RAM; request/release is idempotent.
- YM: a key-off must release; envelope rates must not depend on host speed; channel-6 DAC must not
  emit garbage when unused.
- Mixer: output length per second must be exactly 48 000 samples (stereo frames), and a second run
  must produce the same bytes.
