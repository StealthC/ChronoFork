# Timers, Controllers and Interrupts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire YM2612 Timers A/B to the Z80 IRQ and the VDP H-int counter to the 68000, and implement the full TH-latched 3-/6-button controller protocol on ports 1–2.

**Architecture:** A `controller.rs` state machine per port; YM timer countdowns produce Z80 IRQ requests; the VDP owns the H-int counter and level-4 request; the backend aggregates and delivers interrupts under the existing mask rule. Payload moves to `CFMD68K7` v7.

**Tech Stack:** Rust 2024, `chronofork-core`, `chronofork-backend-api`, `chronofork-megadrive`, `chronofork-cli`.

**Spec:** `docs/superpowers/specs/2026-11-17-8.5-timers-controllers-design.md`

## Global Constraints

- No `unsafe`, no new third-party dependency, no `unwrap()` in production code; typed errors.
- Determinism: timer/controller timing derives only from master cycles; no host input.
- Port 3, analog, keyboard and interrupt levels 2/3/5 remain out of scope and documented.
- State changes are reject-only and versioned (payload v7); older versions rejected.
- Every task ends with its own tests passing and a commit.

## Review Focus

- A controller read without a preceding TH write must return the documented default phase, not stale
  data from another port.
- The 6-button timeout must reset exactly at the documented master-cycle boundary and not on adjacent
  cycles.
- A disabled or masked YM timer must not request an IRQ; enabling it later must not replay missed
  overflows.
- HInt must fire at the programmed line offset, once per line, and not at line 0 of the frame.
- Two interrupt sources pending at one boundary must deliver in the documented priority without
  dropping the second.
