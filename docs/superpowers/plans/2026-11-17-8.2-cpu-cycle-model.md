# Complete 68000 and Cycle Time Model Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the full documented MC68000 with per-instruction cycle accounting and make master-clock cycles the backend's canonical time base.

**Architecture:** `cpu.rs` becomes a module tree (state, decode, effective address, execution groups, timing). `M68000::step` returns `InstructionOutcome { cycles }` (68000 cycles); the backend advances `Tick` by `cycles * 7` master cycles and the interrupt scheduler runs on the 3420-master-cycle scanline. Snapshot/hash magics move to v4 with `CFMD68K4`/`CFMDSTATE4`/`CFMDCONF4`.

**Tech Stack:** Rust 2024, `chronofork-core`, `chronofork-backend-api`, `chronofork-megadrive`, `chronofork-cli`, Python 3 (oracle harness only).

**Spec:** `docs/superpowers/specs/2026-11-17-8.2-cpu-cycle-model-design.md`

## Global Constraints

- No `unsafe`, no new third-party dependency, no `unwrap()` in production code; typed errors.
- Guest faults are 68000 exceptions; host faults stay typed Rust errors. Never silently ignore an
  unrecognised opcode.
- Canonical time is integer master cycles: 68000 cycle = 7, line = 3420, NTSC 262 lines, PAL 313.
  No floating point or host clock in canonical state.
- Determinism: identical input sequence and start state produce identical tick, state hash and
  exception sequence in every run.
- State/hash/format changes are reject-only and versioned (v4); v1–v3 rejected.
- Every task ends with its own tests passing and a commit; never leave the workspace uncompilable.

## Review Focus

- Privilege: `MOVE to SR`, `STOP`, `RESET`, `RTE`, `MOVE to USP` in user mode must raise vector 8
  (privilege violation) and change nothing else.
- Address error: odd-address and unmapped accesses during instruction execution must take vector 3
  with the documented frame; a failed push must not half-update state.
- Flags: `X` semantics for `NEGX`/`ADDX`/`SUBX`/`ROXL`/`ROXR` and `V` for signed overflow must match
  the documented behaviour; `DIVS` overflow must set `V` without writing the quotient.
- Cycle table: EA cost must be added exactly once; a `MOVE.L #imm,Dn` that costs 12 cycles and an
  `MOVE.W (An),Dn` that costs 8 are the two regression anchors.
- Tick: no path advances `Tick` by a non-integer number of master cycles or by a host-time value.
