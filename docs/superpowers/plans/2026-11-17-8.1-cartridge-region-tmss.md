# Cartridge, Region, TMSS and Boot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Model the cartridge — header, region, Sega mapper, SRAM and TMSS lockout — and prove a synthetic cartridge boots deterministically with all of it exercised.

**Architecture:** A new `cartridge.rs` owns the ROM image, parsed header, mapper register file, 64 KiB SRAM and TMSS latch; `MegadriveBus` delegates the cartridge windows to it. The factory derives the video standard from the header, and the snapshot/config hashes move to v3 with `CFMD68K3`/`CFMDSTATE3`/`CFMDCONF3`.

**Tech Stack:** Rust 2024, `chronofork-core` (SHA-256), `chronofork-backend-api`, `chronofork-megadrive`, `chronofork-cli`.

**Spec:** `docs/superpowers/specs/2026-11-17-8.1-cartridge-region-tmss-design.md`

## Global Constraints

- No `unsafe`, no new third-party dependency, no `unwrap()` in production code; typed errors.
- Determinism: no host wall-clock, environment or filesystem input to canonical state. SRAM import is construction-time host policy only.
- Emulated state changes are versioned and reject-only: payload v3, state hash v3, config hash v3; v1/v2 rejected.
- TMSS defaults to `Disabled` and the mapper defaults to identity, so existing bytes, demos and M3 fixtures stay valid except for the documented hash-version bump.
- Never read or commit ROM bytes in code or tests; fixture tests skip with an explicit reason when `.research/roms/` is absent.

## Review Focus

- A ROM shorter than its declared `rom_end` must not read past the image; a bank page beyond the image must be a typed error, not zero-fill.
- Region letters other than `J`/`U`/`E` (and a missing region byte) must be rejected before any state is built.
- SRAM writes while `0xA130F1` bit 1 is set must be rejected atomically (no partial byte).
- With TMSS enabled, a VDP write before the unlock must change nothing, including the VDP address latch.
- Snapshot restore must leave the machine untouched on any rejected payload or mapper/SRAM length.

fn header_rom(region: &str, rom_end: u32) -> Vec<u8> {
    let mut rom = vec![0xAA; 0x4000];
    rom[0x100..0x110].copy_from_slice(b"SEGA MEGA DRIVE ");
    rom[0x120..0x130].copy_from_slice(b"KID CHAMELEON   ");
    rom[0x150..0x160].copy_from_slice(b"KID CHAMELEON   ");
    rom[0x180..0x18E].copy_from_slice(b"GM MK-1010 -00");

    rom[0x1A4..0x1A8].copy_from_slice(&rom_end.to_be_bytes());
    let mut checksum = 0u16;
    for (index, byte) in rom.iter().enumerate() {
        if (0x18E..0x190).contains(&index) {
            continue;

        checksum = checksum.wrapping_add(u16::from(*byte));

    rom
}

- [ ] **Step 3: Implement the header parser**

Add `pub mod cartridge;` to `lib.rs`. In `cartridge.rs`:
- `Cartridge::parse` validates `8 <= len <= 0x400000 * 64` (the mapper's 9-bit page limit is checked when a bank is selected; the construction limit is `0x4000_0000`, documented as the mapper's 64 MiB addressable ceiling).
- Require the system string at `0x100` to start with `SEGA `; classify `SEGA MEGA DRIVE` and `SEGA GENESIS`, reject any other system with `MissingSegaSignature` (the message names the found string, bounded to 16 bytes).
- Decode the four text fields as bounded ASCII: take up to the field length, trim trailing spaces and NULs, stop at the first non-printable byte, and use `String::from_utf8_lossy` only after that bound.
- Read `checksum_stored` at `0x18E`, `rom_start` at `0x1A0`, `rom_end` at `0x1A4`, SRAM spec at `0x1B0` (start) and `0x1B4` (end); a zero/zero SRAM pair means `None`.
- Compute the checksum as the wrapping byte sum skipping `0x18E..0x190`; store both values and never fail construction on a mismatch (diagnostic only).
- Parse region from `0x1F0`: consume exactly the declared bytes (`J`, `U`, `E`; reject any other non-NUL byte). If the declared end exceeds the image length, return `HeaderMismatch`.
- Add `test_support::rom_path(name: &str) -> Option<PathBuf>` behind `pub mod test_support` in `lib.rs` that resolves `$CHRONOFORK_ROM_DIR` or `$HOME/projects/ChronoFork/.research/roms/` (falling back to `<repo>/.research/roms/` via `CARGO_MANIFEST_DIR/../../.research/roms`) and returns `None` when the file is missing.

- [ ] **Step 3: Implement mapping**

- Window 0 is `0x000000..=0x07FFFF` fixed to bank 0. Windows `1..=6` start at `0x080000 + (i - 1) * 0x80000` and use `banks[i]`.
- `read8` translates `address` through the window table to `bank * 0x80000 + offset`; if the translated offset is `>= rom.len()`, return `UnmappedRom { address }`.
- `read16`/`read32` reject odd addresses first (`OddAddress` is added to `CartridgeError` and mapped by the bus), then read bytes through `read8` without mutating state.
- `write8` accepts only `0x00A1_30F0..=0x00A1_30FF` (mapper) and the SRAM window when visible (Task 3); any ROM-window write is `WriteProtected { address }`.
- Mapper writes: `0xA130F1` sets SRAM enable/protect bits (Task 3); odd offsets `0xF3, 0xF5, …, 0xFF` set `banks[(offset - 0xF3) / 2]` masked to 9 bits. Even offsets are stored in `raw_registers` for diagnostics only.
- `set_bank` validates the window and applies the 9-bit mask.

- [ ] **Step 3: Implement TMSS**

- `Tmss::new(Disabled)` starts unlocked; `Enabled` starts locked.
- `write_long` accepts only `0xA14000..=0xA14003`; bit 9 of `value` set means unlock (`locked = false`). Writes elsewhere are ignored (the bus rejects them as unmapped).
- Version register: `(export as u8) << 7 | (pal as u8) << 6 | 0x20 | (tmss_enabled as u8)`, where `export = header.region.is_export()` and `pal = video == Pal`. For `JUE` + NTSC with TMSS enabled this is `0xA1`; for `J` + PAL with TMSS disabled it is `0x60` (plus `0x01` when enabled).
- In `bus.rs`, before dispatching a VDP write (`0xC00000..=0xC0000F`), consult `tmss.vdp_writes_allowed()`; when locked, consume the write and return `Ok(())` without touching the VDP. Map `0xA10001` to `version_register`; map `0xA14000..=0xA14003` writes to `tmss.write_long`.
- Add the TMSS latch to `MegadriveBus` and expose `pub fn tmss(&self) -> &Tmss`.
